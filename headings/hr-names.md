# Croatian name forms — taken from the shipped BKJ text, not from habit

A heading spelling a name differently from the verse under it reads as a bug, so every one of
these was counted in `bkj/*.json` before use. The left column is where an obvious-looking Croatian
form is *wrong for this edition*.

| English | BKJ uses | NOT |
|---|---|---|
| the LORD | GOSPOD | Gospodin (that renders "the Lord") |
| Zedekiah | Zedekija | Sidkija |
| Ahaziah | Ahazija | Ahazja |
| Amaziah | Amazija | Amasja |
| Azariah | Azarija | Azarja |
| Bezalel | Bezalel | Besalel |
| Jezebel | Jezabela | Izebela |
| Abigail | Abigail | Abigajila |
| Ben-hadad | Benhadad | Ben-Hadad |
| Artaxerxes | Artakserks | Artakserkso |
| Cain | Kajin | Kain |
| Malta | Melita | Malta |
| Saul (of Tarsus) | Savao / Savle | Šaul (that is king Saul) |
